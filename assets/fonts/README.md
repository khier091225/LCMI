# Local brand fonts

Poppins (600, 700) and Source Sans Pro (400, 600) retain the typography already referenced by the original website. The font files were fetched from the Google Fonts CSS API and converted from TTF to WOFF2 without changing the typeface design.

- Poppins source: https://fonts.googleapis.com/css2?family=Poppins:wght@600;700&display=swap
- Source Sans Pro source: https://fonts.googleapis.com/css2?family=Source+Sans+Pro:wght@400;600&display=swap
- Poppins OFL notice: https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt
- Adobe Source Sans OFL notice: https://github.com/google/fonts/blob/main/ofl/sourcesans3/OFL.txt

The local OFL text files accompany the distributed fonts. Pages load these local assets and do not contact the Google Fonts service.
